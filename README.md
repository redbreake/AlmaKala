# 2025 Anime Analysis Landing Page

Premium landing page for the YouTube video **"2025: ¿El PEOR AÑO de la HISTORIA del Anime?"** by Kalathras (Lolweapon).

## Features
- **Data Visualization**: Interactive Chart.js donut chart showing the "Soul vs Industrial Noise" ratio.
- **Detailed Critiques**: Clickable anime posters that reveal specific opinions and quotes from the video transcript.
- **Responsive Design**: Modern, dark-themed UI with neon accents, glassmorphism, and smooth scroll animations.
- **Automated Assets**: Anime posters and thematic art integrated via high-performance automation scripts.
- **Searchable List**: A complete searchable database of over 70 animes categorized as "Industrial Noise".

## Technologies Used
- HTML5 / CSS3 (Vanilla)
- JavaScript (ES6+)
- [Chart.js](https://www.chartjs.org/)
- Google Fonts (Orbitron & Outfit)

## How to View
Simply open `index.html` in your browser or visit the live link (if deployed via GitHub Pages).
